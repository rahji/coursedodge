# CourseDodge

Coursedog has this annoying "feature" that disables highlighting text for copying to the clipboard.

This is a Chrome extension that disables that disabling.

## Installing

1. Click the green "Code" button above and choose "Download ZIP"
2. Unzip the file on your computer by double-clicking the .zip file
3. In chrome, type this in the URL field: `chrome://extensions`
4. Turn on "Developer Mode" using the switch in the upper right corner
5. Click the "Load Unpacked" button that just appeared
6. Navigate to the unzipped folder and choose the folder called "coursedodge"

## Usage

Go about your normal business in Coursedog and you'll see that you can now highlight and copy text to the clipboard.

You'll have to be aware that changing the text on the page is not actually changing the course/proposal. If 
you think that's too confusing, you can always turn off the extension by clicking the "Extensions" puzzle piece icon on the Chrome
toolbar.
